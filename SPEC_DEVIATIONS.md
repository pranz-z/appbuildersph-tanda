# Spec deviations

Audit date: 2026-10-10. Baseline: `TANDA_SPEC.md` v2. Scope: the **current working checkout**, including tracked edits and untracked source, tests, and assets; not just committed HEAD (`3b476b1`). Git history establishes downloader (`3b476b1`), import/logging (`3b8ce44`), Whisper (`2450b66`), and LLM spike (`e1eca5e`) work. Much of the current product implementation is not committed; those hashes do not establish delivery of the later features.

**Status:** “Complete” means connected in current code, not device acceptance. “Partial” means a stated requirement or capability remains missing. “Unverified” means evidence is insufficient. Tests cited below were inspected, **not executed for this documentation audit**. No build, license lookup, or phone test was performed. Prior agent reports are not treated as repository test evidence. Reasons are stated only where repository comments/documentation supply them; otherwise the product rationale is not recorded in the repository.

## 3. Still within the spec — not additional features

- **On-device stack:** Whisper small int8 with base fallback, Qwen2.5 1.5B Q4_K_M/llama.cpp with GBNF, isolates, Drift SQLite, durable 16 kHz mono WAV capture and `just_audio` citation playback follow §§5–6. Qwen selection, CPU backend and plugin wrappers are implementation choices within the specified stack (`core/providers.dart`, `services/`, `pubspec.yaml`). Real STT/LLM providers are wired; test fake services are not their production substitutes.
- **Typed capture/questions, editable review, evidence highlighting, uncertain-field indicators, progress, explicit confirmation, retry and manual entry** are P0 requirements, not feature expansion. Current limitations are listed above (`tala_screen.dart`, `tanong_screen.dart`, `test/memory_persistence_test.dart`).
- **Stable IDs, timestamps, open/done state, audio paths and confirmed SQLite retrieval** are specified (§7). Typed memories having no audio path fits the nullable schema and typed fallback. Nullable embedding storage does **not** mean embeddings are implemented.
- **Deterministic answers/reminders without LLM polish** are allowed defaults (§§8.2–8.3). Ambiguity choices support “never guess”; they do not replace required hybrid retrieval. Transcript/audio citations, missing-audio error handling, open-loop filtering/sorting, persistent Done and computed per-person loan totals implement P0 (§4; `local_memory_ask.dart`, `open_loops.dart`, `reminder_draft.dart`, related screens/tests).
- **Real UID transmit measurement and honest Unavailable state** fit §10's optional TrafficStats source and no-hard-guarantee rule. `core/locality_meter.dart` and `MainActivity.kt` measure UID transmit deltas, including downloader requests, **not received model payloads or all device traffic**. Actual STT/LLM attempt wrappers increment even on failure (`core/session_usage.dart`, `test/locality_meter_test.dart`). Connectivity/counters are required; their placement is the deviation.
- **Model presence/error checks, keeping the screen awake, and optional smaller Whisper fallback** are already specified. The startup “Continue anyway” bypass supports typed/local access, but does not establish that every model is loaded (`first_run_screen.dart`, `main.dart`).
- No connected P1 due-date banner, formal tone set, weekly summary, P2 sync, OCR, notifications or cloud inference implementation was found. Their absence is not an unreported delivered feature or a required P0 addition.
